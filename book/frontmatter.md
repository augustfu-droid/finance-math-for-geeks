# 前言：为什么写这本书

你很可能已经会写 Python，调过 XGBoost、跑过回测框架、部署过风控规则。你知道梯度下降能让模型收敛、知道 VaR 是风险度量、知道协整可以做配对交易。但当有人追问"为什么 XGBoost 要用泰勒二阶展开""为什么正态假设失效会让 VaR 系统性低估尾部风险""为什么没固定随机种子会让整条自动化流水线随机挂起"时，你会发现自己知道结论，却讲不出底层的数学与工程因果。

这不是你的问题。金融科技行业的教育有一个断层：**学校教定理，培训班教调包，中间缺了一环——把数学直觉、代码实现、业务落地，再加上生产环境的血泪教训，全部串起来。**

这本书要填补的正是这个断层。它不是从公理出发的数学教材，也不是 import 一把梭的调包教程。它是一本**连接手册 + 排雷手册**：每一个数学概念，都用固定的六个模块讲透——

1. **💡 大白话唤醒直觉**：先用生活常识或股票走势把本质讲明白，绝不一上来扔定理。
2. **📐 极简公式推导**：只给核心精简公式，步骤写全，用 LaTeX 排版。
3. **💻 Python 跑直觉**：一段可独立运行、带详细中文注释的代码，画图或打印数值，亲手验证原理。
4. **🚀 金融/AI 业务映射**：两句话点透，这个数学概念在衍生品定价、量化多因子风控或机器学习中是什么"零部件"。
5. **🛡️ 系统级 QA 灾难与防坑指南**：由一位 16 年金融科技测试架构师视角，复盘典型的生产级 Bug（时间戳重叠除零、张量维度崩溃、浮点截断信号反转、未来函数穿越、随机种子未固定、正态假设失效风控穿透……），并给出工程级的断言拦截方案。
6. **📝 即学即练**：每个模块后紧跟一道小题与参考答案要点，做到边学边测、即学即练。

> 所有 QA 灾难案例均为基于公开工程知识的虚构脱敏演绎，不指向任何真实机构或事件，仅用于传授防坑思维。

## 这本书为谁而写

- **有工程底子、想理解模型本质的极客**：你熟悉 Python 与软件工程，想补上数学这一环。
- **从开发/测试转量化或风控的人**：你有扎实的系统与质量直觉，缺的是金融数学工具。
- **AI 背景想进金融的人**：你懂深度学习，但不知道这些数学在金融里具体是哪个零部件。

## 阅读建议

这是一本工具书，既可以从头到尾通读建立体系，也可以按需取用：工作中遇到优化器选择，翻第一篇；要做向量化回测提速，翻第二篇；要做违约概率与 VaR，翻第三篇；要做配对交易与时序分析，翻第四篇；要理解期权定价、有效前沿与债券久期，翻第五篇。每一节都自带可运行代码与练习题，学完即可上手验证。

关于这本书的定位：它从量化交易常用的工具出发，但刻意把视野拓展到更完整的**金融数学**版图——不仅讲优化器与回测，也讲随机分析（布朗运动、伊藤引理）、衍生品定价（Black-Scholes）、组合理论（均值-方差、CAPM）与固定收益（久期、凸性）。这些才是支撑整个现代金融工程的数学底座。

# 全书导航

本书共五篇、十三章、四十四节，覆盖代码驱动金融数学与 AI 风控所需的五大数学支柱。每一节都遵循统一的六模块结构。

| 篇章 | 核心数学 | 典型金融/AI 应用 |
|------|----------|------------------|
| 第一篇 微积分与算法寻优 | 极限、导数、偏导、链式法则、泰勒展开、梯度 | 梯度下降、反向传播、期权希腊字母、XGBoost 二阶寻优 |
| 第二篇 线性代数 | 向量、矩阵乘法、逆矩阵、秩、特征值、SVD | 向量化回测、PCA 降维、正交 Alpha 因子、正规方程 |

| 第四篇 随机过程与时序分析 | 随机游走、平稳性、协整、隐马尔可夫、蒙特卡洛 | 均值回归、配对交易、牛熊状态识别、衍生品定价 |
